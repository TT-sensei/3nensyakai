# 3nensyakai

小学校3年生向けの社会科を、短いクエストでくり返し学ぶWeb教材です。

## 学習できる単元

- まわりの様子
- 市の様子
- スーパーのくふう
- 工場ではたらく人
- 火事からまちを守る
- 事故からまちを守る
- まちのうつりかわり

## edu-kitの考え方

問題文・正答・10問の学習構成は教材の中心として保護し、画面の共通部分にedu-kitの考え方を取り入れています。

- 問題を最優先にした、タブレットで押しやすい選択肢
- まちがいの後に解説とヒントを置き、次の行動へ進める流れ
- 6人の通常版NAVIキャラによる短い案内と励まし
- 社会科の学びと結びついたバッジコレクション
- localStorageによる学習成果の保存

バッジ画像はedu-assets、通常版NAVIキャラはnavi-character-、共通の見た目と演出はedu-effectsを参照しています。
